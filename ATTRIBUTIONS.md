# Third-party attributions

OpenInquiry's application foundation uses no third-party images, icons, or bundled font files. The interface marks, diagrams, and SVG icon are original to this reference implementation.

Runtime and development dependencies retain their own licenses. Exact package versions are recorded in `package-lock.json`; package license notices remain available in each installed package and its upstream distribution.

System font fallbacks are referenced by name only and are not redistributed with this repository.

No screenshots or video assets are currently stored in the repository. Any final Devpost media must be reviewed before publication and recorded here if it introduces third-party material.
